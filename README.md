## How to Read This Table (for Colleagues)

* **Canonical Dataset**: What you demo in class (stable, controlled)
* **Discipline Columns**: What *could* or *should* be used by students
* **[GAP] cells**:

  * Highest-value opportunities for:

    * Student dataset discovery
    * Future course enrichment
    * Making non-IS majors feel “seen”

## Strategic Insight (Important)

You do **not** need to fill every gap immediately.

A powerful rollout strategy is:

1. Pick **1–2 gaps per week** as *optional dataset discovery targets*
2. Let students populate them during the inaugural pilot
3. Promote the best into next semester’s canonical or lab datasets

Over 2–3 semesters, this matrix becomes:

> A **discipline-complete analytics curriculum**, co-built by students.
